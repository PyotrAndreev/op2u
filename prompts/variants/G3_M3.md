# G3_M3 — Attention allocation by classification

Parent: `G2_M1`
Affected stage: `ranking` only

Apply V1–V4, G1_M3 strict ACT_NOW, and G2_M1 conservative weekly allocation unchanged.

Exactly one mutation: schedule current-week effort for ACT_NOW by default. A PREPARE_NEXT action may consume this week's budget only when it builds a specifically required reusable artifact for a verified upcoming window and has an internal decision deadline. MONITOR must always have zero scheduled_this_week_minutes and explicitly say no action requested this week. Reallocate attention to the strongest ACT_NOW paths; do not fill spare budget. Persist scheduled versus deferred classifications and keep total upper-bound scheduled effort at most 360 minutes.
