# G3_M1 — Minimal supported-claim report

Parent: `G2_M1`
Affected stage: `report` only

Apply V1–V4, G1_M3 strict ACT_NOW, and G2_M1 conservative weekly allocation unchanged.

Exactly one mutation: for every report statement about status, deadline, eligibility, submission format, travel/support, location, funding, or requirements, require one persisted verification record containing an exact quote, official URL, and retrieval time that directly entails that statement. Copy those fields into a `claim_ledger`. If the quote supports only status/deadline but not format or eligibility, state only status/deadline and list the rest as unknown. Omit secondary detail rather than paraphrasing beyond the quote. The report may not browse or create evidence. Preserve ranking and scheduled actions unchanged unless a factual claim required to justify ACT_NOW lacks direct support; then render it as a hard inconsistency, not a repaired claim.
