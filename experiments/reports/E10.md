# E10 — Constrained serendipity

**Master definition:** Obvious maximum fit only vs at most one constrained serendipitous item.

**Hypothesis:** Constrained serendipity increases useful novelty without evidence/actionability regression.

**Primary readout:** Qualified novelty, diversity, and hard-gate rate.

**Status:** **partial**. V7 exists and the cumulative ladder includes a constrained serendipity capability, but there is no isolated V6-versus-V7 repeated comparison with qualified-novelty scoring. The four blinded comparisons concern later frontier reports, not this E10 endpoint.

No observed report should be credited with serendipity merely because it contains multiple opportunity types. Any production serendipity slot must pass the same evidence, liveness, bridge, action, count, and effort gates.
