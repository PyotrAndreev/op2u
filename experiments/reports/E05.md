# E05 — Persisted stages

**Master definition:** Monolithic agent vs explicit persisted stages.

**Hypothesis:** Staging improves provenance, diagnosability, and preservation of discoveries.

**Primary readout:** Artifact completeness, source continuity, final/artifact consistency.

**Status:** **partial**. V0–V3 are monolithic report runs and V4 onward are staged runs, so the inventory provides a useful architecture contrast. It is not a matched repeated A/B comparison: prompts, stage behavior, and cumulative capabilities change together, and no predeclared artifact-continuity score was run across both arms.

The staged frontier runs persist profile, triggers, verification, ranking, and report artifacts, making diagnosis possible. That is implementation evidence, not a measured E05 effect. Do not claim improved provenance or consistency beyond the persisted artifact observations.
