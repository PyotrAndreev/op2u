# E01 — Dynamic profile state

**Master definition:** Flat profile vs explicit durable facts, active trajectories, current context, reusable assets, constraints, and decisions.

**Hypothesis:** Dynamic-state extraction increases contextual actionability and reduces generic output.

**Primary readout:** State completeness, actionable top-3 precision, genericity.

**Status:** **partial**, not a controlled E01 A/B cell. The V0–V1 screen changes the cumulative prompt and supplies only one run per side; it does not isolate this factor under a repeated matched comparison. Later staged runs visibly use profile-state artifacts, but they also change other capabilities. No claim of causal improvement or significance is warranted.

**Evidence:** V0 produced a closed NLnet `ACT_NOW` recommendation; later staged reports used explicit project/asset bridges. These are diagnostic observations, not an E01 estimate. A real E01 requires matched flat/state prompts, preserved candidate pools, and repeated state-completeness and genericity scoring.
