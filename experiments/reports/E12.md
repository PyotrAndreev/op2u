# E12 — Funnel-stage likelihoods

**Master definition:** Binary relevant/irrelevant feedback vs funnel-stage likelihoods.

**Hypothesis:** Funnel evaluation separates interesting recommendations from actionable ones.

**Primary readout:** Noticed→opened→first-action→submitted proxy distribution.

**Status:** **not_run**. The persisted suite contains rubric judges and pairwise reports, not user feedback or funnel-stage likelihood observations. No opened, first-action, submitted, or successful-outcome labels were collected. Reports must not manufacture these outcomes from judge acceptance.

E12 therefore has no result, variance estimate, or significance claim. It requires a separately instrumented feedback study with clear consent, stage definitions, and the current proxy limitations stated.
