# EUSP P1 synthetic-neutral experiment record

- **Hypothesis:** Requiring explicit status, timing, and participation-route evidence maps will make P1 readiness eligibility reject unsupported or no-longer-live selections.
- **Treatment:** The P1 report serialization contract and deterministic packet preflight require three material-claim kinds, each mapped to direct official-primary evidence.
- **Method:** Exercise the treatment with an anonymized synthetic fixture and deterministic regression cases for missing claim maps and stale, closed, or expired selections in both selected buckets. No profile, run artifact, or live-model call is retained in this record.
- **Measurement:** Packet grounding/liveness gates, gate-derived eligibility, and promotion eligibility under two paired orientations.
- **Result:** Missing material mappings and stale/closed/expired ACT_NOW or PREPARE_NEXT selections fail deterministic gates; the partial comparison is **not promoted** because the required fully eligible, order-stable paired result is not established here.
- **Non-promotion:** No frontier or production prompt is promoted by this record.
- **Profile-scoped limitations:** This is a synthetic, neutral regression evaluation rather than a generalization result. It does not establish performance for any person, location, preference set, or private profile, and contains no retained private profile or run data.
